# Fstly Gallery

**Fstly Gallery** es una galería de fotos y videos para Android con **bóveda cifrada**, **PIN de seguridad** y **papelera de reciclaje**. Sin Google Play Services, sin analytics, y con licencia GPLv3.

## Características

### 🔐 Seguridad
- **PIN de seguridad** para acceder a la app
- **Bóveda cifrada** para fotos privadas
- **Sin recuperación de PIN** (seguridad real: si lo olvidás, perdés el acceso)
- **Sin Google Play Services**
- **Sin analytics**
- **Sin permisos innecesarios**

### 📸 Galería
- Visualización de fotos y videos
- **Favoritos**
- **Papelera de reciclaje**
- **Modo oscuro** automático
- **Fuentes personalizables**
- **Grilla adaptable**
- **Editor**

### 🎨 Interfaz
- **Material 3**
- **Modo oscuro** automático
- **Diseño limpio y minimalista**
- **Iconos vectoriales**

### ⚙️ Técnico
- **Kotlin puro**
- **AndroidX**
- **Material 3**
- **API 24+** (Android 7.0 Nougat)
- **Target SDK 34** (Android 14)
- **Sin Google Play Services**
- **Sin Firebase**
- **Sin analytics**
